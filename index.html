Project Overview

This project demonstrates a complete CI/CD pipeline using GitHub and AWS services.

Whenever code is updated, it is automatically built and deployed to a live server without manual intervention.

Pipeline Workflow

1. Code is pushed to GitHub repository.

2. AWS CodePipeline detects changes automatically.

3. CodeBuild builds and packages the application.

4. CodeDeploy deploys the application to EC2.

AWS Services Used

  • Amazon EC2 - Hosting server
  • AWS CodePipeline - CI/CD orchestration
  • AWS CodeBuild - Build automation
  • AWS CodeDeploy - Deployment automation
  • Amazon S3 - Artifact storage

Benefits of CI/CD

✔ Faster deployments

✔ Reduced human errors

✔ Continuous delivery

✔ Reliable and consistent updates
